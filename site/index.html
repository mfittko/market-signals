Do not miss the course of a move.

market-signals is a signal desk for one trader. It tells you when a move starts, follows it, and says when it is over. Agents advise. Nothing trades with real money.

  • Alerts that become a short story: it started, it continued, it reversed, or it faded.
  • Agents that read the context around a signal, explain it, and propose what to do.
  • Plain code that manages every open position. No model sits in the exit loop.
Where it stands A working prototype in advisory mode, run against paper money. The first public version is v0.2.0.
